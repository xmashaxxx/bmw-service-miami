# BMW Service Miami Legacy Design Template

Earlier design iteration for the BMW Service Miami client website. This version was developed and presented but ultimately not chosen as the client preferred a different aesthetic direction. Preserved as a reusable template for future automotive client projects.

**Live preview:** [xmashaxxx.github.io/bmw-service-miami](https://xmashaxxx.github.io/bmw-service-miami/)  
**Production site (final version):** [bmwrepairshop.net](http://bmwrepairshop.net/)

## Context

Web development rarely ships on the first design. This repo represents one of several full design iterations built for the BMW Service Miami project; a working, polished alternative that went through complete development before the client selected a different direction.

Keeping rejected-but-complete designs as separate repos serves two purposes:
1. **Portfolio depth** — shows the range of design directions explored for a real paid project
2. **Template library** — a ready-to-adapt starting point for future automotive service clients

## What's Different From the Final Version

This design uses a different visual language — color palette, layout structure, and typography choices that skewed toward a different aesthetic than the production site. Both are fully functional. The client's preference drove the selection, not technical quality.
